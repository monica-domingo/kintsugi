# Raku Application

## Purpose

Raku is a demonstration and showcase application for the **Kintsugi Component Library**. Its primary purpose is to provide a real-world example of how to integrate and utilize the components from the `@kintsugi/kintsugi` library. It serves as:

-   A **live catalog** of Kintsugi components in action.
-   A **testing ground** for new and existing Kintsugi components to ensure they function correctly in a practical application environment.
-   A **developer resource** for understanding how to import, configure, and use Kintsugi components.
-   A **reference implementation** demonstrating best practices for building applications with Kintsugi.

While Raku is a fully functional React application, it is not intended as a standalone product for end-users. Instead, it's a tool for developers working with or contributing to the Kintsugi Component Library.

## Installation and Setup

To run the Raku application locally, follow these steps:

1.  **Clone the Monorepo:**
    If you haven't already, clone the entire Kintsugi monorepo:
    ```bash
    git clone https://github.com/monicadomigop/kintsugi.git
    cd kintsugi
    ```

2.  **Install Dependencies:**
    Navigate to the root of the monorepo and install all necessary dependencies for Raku and other packages (including Kintsugi). This project uses Nx, which manages dependencies for all packages.
    ```bash
    npm install
    # or
    yarn install
    ```
    This command will install dependencies listed in the root `package.json` and link the local packages (like `@kintsugi/kintsugi`) correctly.

## Running the Application Locally

Once the dependencies are installed, you can run the Raku application using the following Nx command from the **root of the monorepo**:

```bash
nx run raku:serve
```

This command will:
-   Build the Kintsugi component library if it hasn't been built already or if changes are detected.
-   Start a development server for the Raku application.
-   Typically, Raku will be available at `http://localhost:4200` (the exact port might be configured in `project.json` or output to the console).

Open your browser and navigate to the specified address to see Raku in action.

## Integration with Kintsugi Component Library

Raku is tightly coupled with the Kintsugi Component Library. Here’s how they are integrated:

-   **Local Package Dependency:** Raku depends on the `@kintsugi/kintsugi` library. In the Nx monorepo setup, this dependency is typically linked locally. This means that when you make changes to the Kintsugi library, they can be reflected in Raku when it's rebuilt (often automatically by `nx serve`).
-   **Component Usage:** Raku imports and uses components directly from `@kintsugi/kintsugi`. You can browse the Raku application's source code in `packages/app/raku/src/app/` to see various examples of how Kintsugi components are implemented.

    For example, to use a `Button` from Kintsugi:
    ```tsx
    import { Button } from '@kintsugi/kintsugi';

    function MyFeatureComponent() {
      return (
        <div>
          <Button variant="primary" onClick={() => alert('Hello from Kintsugi!')}>
            Kintsugi Button
          </Button>
        </div>
      );
    }
    ```

-   **Storybook:** While Raku shows components in a full application context, individual Kintsugi components can also be explored in isolation using Storybook. To run Storybook for Kintsugi components (often configured via Raku's project settings in a monorepo):
    ```bash
    nx run raku:storybook
    ```
    This usually opens at `http://localhost:4400`.

## Building for Production

To create a production-ready build of the Raku application, run the following command from the **root of the monorepo**:

```bash
nx build raku
```

This command will generate optimized static assets in the `dist/packages/app/raku` directory (or a similar path configured by Nx). These assets can then be deployed to any static web hosting service.

## Deployment Notes

As Raku is primarily a demonstration application, there are no specific deployment pipelines set up in this repository. The production build generated by `nx build raku` can be deployed manually to services like Vercel, Netlify, GitHub Pages, or any other static hosting provider.
