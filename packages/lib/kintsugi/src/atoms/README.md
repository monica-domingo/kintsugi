# Atoms

Atoms are the foundational building blocks of our component library, adhering to the principles of Atomic Design. They represent the smallest, indivisible UI elements and cannot be broken down further without losing their functional meaning.

## Purpose

- **Basic Functionality:** Atoms provide the most fundamental UI interactions and displays, such as buttons, input fields, labels, icons, and text elements.
- **Reusability:** Designed for maximum reusability, atoms can be combined in various ways to create more complex components (Molecules and Organisms).
- **Consistency:** They ensure a consistent look and feel for the most basic UI elements across the application.
- **Building Blocks:** Atoms serve as the core ingredients for all other components in the Kintsugi library.

## Available Atoms

The following atom components are available:

-   **[Button](./button/)**: A versatile button component used for triggering actions. It supports various styles (primary, secondary, tertiary), sizes, and states (disabled, loading).

Additional components will be added here as the library grows.
