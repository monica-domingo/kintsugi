# Molecules

Molecules are the next level in the Atomic Design hierarchy within the Kintsugi component library. They are relatively simple groups of UI elements composed of two or more Atoms functioning together as a single unit.

## Purpose

- **Combined Functionality:** Molecules take individual Atoms and combine them to perform a specific, singular task. For example, a search form might consist of an Input atom and a Button atom.
- **Building Blocks for Organisms:** They serve as the building blocks for more complex components known as Organisms.
- **Encapsulation:** Molecules encapsulate a small piece of functionality and UI, making them reusable and easy to manage.
- **Contextual Grouping:** They provide context to Atoms by grouping them in a meaningful way.

## Available Molecules

Currently, there are no molecule components available in this category. Components will be added here as the library grows and Atoms are combined to form more complex UI units.

*(Examples of molecules that might be added: SearchForm (Input + Button), LabeledInput (Label + Input), IconLink (Icon + Link), etc.)*
